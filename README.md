# Chrome AMOLED Privacy Edition (Android APK Builder)

مشروع أندرويد متكامل لبناء متصفح مطابق لـ **Google Chrome** باللون الأسود النقي **True AMOLED (`#000000`)** مع:
- **درع حظر الإعلانات والمتتبعات (Ad & Tracker Blocker)** على مستوى الشبكة.
- **إدارة متقدمة للكوكيز** (حظر كوكيز الطرف الثالث + مسح فوري أو تلقائي).
- **دعم الإضافات (Extensions & UserScripts)**: يتضمن إضافات مدمجة (تحويل المواقع لوضع AMOLED، تخطي إعلانات يوتيوب، تنظيف روابط التتبع) مع إمكانية إضافة أي كود إضافة JavaScript مخصص.
- **دعم كامل لخدمات Google**: يعمل بسلاسة مع محرك بحث جوجل، يوتيوب، Gmail، وGoogle Drive.

---

## طريقة استخراج ملف الـ APK مجاناً عبر GitHub Actions (في 3 دقائق)

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في **GitHub**.
2. ارفع جميع الملفات والمجلدات الموجودة داخل هذا الملف المضغوط (بما فيها مجلد `.github` ومجلد `app` وملف `build.gradle.kts` و`settings.gradle.kts`).
3. بعد رفع الملفات، اضغط على تبويب **Actions** في أعلى المستودع على GitHub.
4. ستجد عملية البناء **Build Android APK** تعمل تلقائياً (أو يمكنك الضغط عليها ثم الضغط على **Run workflow**).
5. انتظر حوالي دقيقتين حتى تتحول العلامة إلى اللون الأخضر ✅، ثم انزل لأسفل الصفحة تحت قسم **Artifacts** واضغط على:
   `Amoled-Chrome-Privacy-Browser-APK`
   ليتم تحميل ملف الـ **APK** الجاهز للتثبيت على هاتفك مباشرة!
